# Plan: redesign the whole desk UI on React + TypeScript + Tailwind 4 + shadcn/ui (refined dark)

Date: 2026-10-04. Builds on the React port merged as 832028a (main). Owner decisions (2026-10-04): stack = React + TS +
Tailwind + shadcn/ui; look = refined dark desk; no Workspace view (keep Inbox, Work, Team as the working views); no
ComplexTrading code copied beyond ideas (its UI has no component library; its stat tile / sparkline / drill-down drawer
patterns inform ours). Classic stays as the fallback.

## Why this stack (owner asked for less code and better design)

- shadcn/ui gives accessible Radix primitives as owned source files: Dialog/Sheet, ToggleGroup (chips), Tabs, Select,
  Popover, Command (cmdk palette), DropdownMenu, Tooltip, Switch, ScrollArea, Sonner toasts. That replaces the hand-written
  focus trap, roving-focus chip groups, menus and toast code (~480 lines of kit) and most of desk.css.
- Tailwind 4 (`@tailwindcss/vite`, CSS-first `@theme`) keeps styling next to markup; one token file defines the look.
- TypeScript catches API-shape mistakes across ~25 screens; pure modules stay `.js` with JSDoc so node:test runs them
  without a TS loader; components are `.tsx`. `npm run typecheck:ui` (tsc --noEmit) runs in the test suite.
- All UI packages are devDependencies (bundled by Vite); the server keeps zero runtime dependencies.

## Design (refined dark desk)

Tokens (Tailwind `@theme`):
- ink `#0E141F` page · surface `#151D2B` panels · raised `#1C2636` controls · line `#263246` hairlines
- text `#E7ECF3` · muted `#8D9AAE` · action `#5B8CFF` · needs-you `#F2B33D` · blocked `#F05252` · shipped `#3FB37F`
- Type: IBM Plex Sans for UI (14/16 body, 20/24 headings), IBM Plex Mono only for data (money, keys, times, sizes).
- Radius: 10 px panels, 8 px controls, full for chips. Hairline borders instead of filled blocks so wide screens can be
  dense without looking heavy. Colour only carries meaning (blue act, amber needs you, red blocked, green shipped).
- Icons: lucide-react, paired with text labels (never icon-only except close/overflow with aria-labels).

- Left rail (icons + labels; collapses to icons at 1024–1279): Inbox, Work, Team, then Research, Pull requests, Desk,
  Settings. Research becomes a first-class page (the owner could not find it inside Settings).
- The four large instrument tiles become one status strip; each item is a link (Needs you, Blocked, Spend, Desk state).
- Command palette (⌘K / Ctrl+K, and a visible search button): open any ticket by name or key, start a research program,
  new ticket, halt/resume desk, go to any page. This is the one memorable element: the desk is keyboard-first.
- Ticket opens in a right Sheet (full screen on phones) with tabs: Decision (brief + actions), Conversation, Run,
  Reviews (PR, product, research), Details. Today it is one long scroll.
- Inbox two columns ≥1280 (decisions | working + blocked). Work keeps four lanes with filter chips. Team cards show
  stat tiles (shipped, first-pass QA, cost/shipped) like ComplexTrading's StatTile.
- Routing: `#/inbox`, `#/work`, `#/team`, `#/research`, `#/prs`, `#/desk`, `#/settings`; ticket overlay `#/work/SD-5`.
  A 40-line hash router; no library.
Review against generic defaults: no all-caps eyebrows, no mono labels, no decorative gradients, no identical card
grid everywhere (Inbox cards, Work lane rows, Team tiles differ by job), dark navy brand kept by owner choice.

## Architecture

- `components.json` (shadcn, style new-york, Tailwind 4, alias `@/`), `ui/src/components/ui/*` generated by the shadcn
  CLI then trimmed; `ui/src/lib/utils.ts` (`cn`). `vite.config.js` adds `@tailwindcss/vite` and `@` alias; base `/app/`.
- Keep and convert: store.js (sync contract, unchanged behaviour), lib/{format,sync,programs}.js (JSDoc-typed),
  shared pure modules in public/ (attention, names, runcard, conversation, avatars, prs-model).
- New: `ui/src/app/` (Shell, Rail, StatusStrip, CommandPalette, router), `ui/src/pages/` (Inbox, Work, Team, Research,
  Prs, Desk, Settings), `ui/src/ticket/` (TicketSheet + tabs), `ui/src/components/desk/` (DecisionCard, SeatAvatar,
  StatTile, Sparkline, ChipChoice wrappers over ToggleGroup, TokenInput, EmptyState), `ui/src/types.ts` (API shapes).
- Remove: ui/src/kit/*, ui/src/views/*, ui/src/sheets/*, styles/desk.css, styles/kit.css (replaced).

## Risks

- Large visual change at once: Classic remains, and the e2e tests pin behaviour (drafts, vanished decisions, focus,
  conditional saves, connectors) across the redesign.
- Radix portals render outside `#root`: the page-behind inertness and focus return come from Radix Dialog now; tests
  must confirm Escape and focus return still work.
- Bundle grows (Radix + cmdk + sonner); lazy-load Research/PRs/Settings pages; measure gzip size in the build output.
- shadcn files are owned code: keep them minimal (only components used) and documented as generated.

## Swarm review (2026-10-04): Codex GPT-5.2 xhigh (591 s, ran the 14 UI tests) + GLM-4.7 (generic; nothing new)

Adopted:
1. Panel focus: capture the opener on open; on close focus it, else its card (`[data-key]`), else `#main`
   (Radix restores only to a Dialog.Trigger; tickets open from code, the palette and links).
2. History: page navigation pushes; opening a ticket pushes `#/page/KEY`; Back closes; closing a cold deep link replaces
   with the page; legacy `#SD-5` works. The skip link must not be a hash link (it would route); it focuses #main.
3. Research refresh is page-aware (`S.view === 'research'`), and stream messages replayed after a snapshot keep their
   refresh flags (they were ignored).
4. Ticket session state (selected decision, tab, drafts, mode, conversation participant/follow/scroll, review correction
   text) lives above the tabs; tabs open in context (decision → Decision, live work → Conversation).
5. Tailwind scans `ui/src` only (`source(none)` + `@source`), never the committed bundle.
6. Contrast: filled blue uses ink text (5.8:1); input borders stronger than decorative hairlines; collapsed rail icons
   have names and tooltips.
7. Stamp discovers `.ts/.tsx` imports of `public/*` and hashes tsconfig.json + components.json.
8. Harness waits for the new shell, not `.instruments`.
9. Budget: initial JS ≤ 160 KiB gzip, CSS ≤ 12 KiB gzip; Research, PRs, Desk, Settings are lazy chunks.
10. Cut from v1: sparklines, ScrollArea, Popover, direct halt/resume/run mutations in the palette (navigation, ticket
    search and "New ticket" only).
Kept with a reason: single-choice chips use Radix ToggleGroup type="single", which renders role="radio" +
aria-checked with roving focus (verified in node_modules); an empty value is ignored so a choice can't be cleared.
Team page shows only snapshot facts (no lifetime stats computed from the latest 40 runs).
